# AI Engineering Interview Preparation

This directory will contain original questions, coding exercises, and system-design scenarios connected to repository projects. Use the [interview template](../docs/templates/interview-question.md) and cite fact-checking sources without reproducing third-party question banks.

Start with the [Senior AI Engineer competency matrix](SENIOR_AI_ENGINEER_COMPETENCY_MATRIX.md) to see how the twelve-project roadmap develops technical, production, system-design, and leadership interview capabilities. The matrix describes planned preparation and must not be treated as evidence of completed work.
